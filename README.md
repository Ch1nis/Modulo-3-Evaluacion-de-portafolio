# Modulo-3-Evaluacion-de portafolio

# To‑Do List — Módulo 3 

Aplicación simple de lista de tareas desarrollada con JavaScript para demostrar conceptos fundamentales y cumplir la evaluación de portafolio del Módulo 3.

## Qué incluye
- Añadir tareas (validación de vacío).
- Mostrar tareas almacenadas en un arreglo.
- Eliminar tareas al hacer clic.
- Uso de funciones para modularizar: agregarTarea(), eliminarTarea(), mostrarTareas().
- Uso de objetos nativos: Date (fecha de creación) y Math (id aleatorio).

## Conceptos de JavaScript demostrados
- Variables y sentencias condicionales (if/else) para validación.
- Arrays y bucles (for/forEach) para gestionar y renderizar tareas.
- Funciones para separar responsabilidades.
- Objetos preconstruidos: Date y Math.

## Estructura recomendada
- index.html — Interfaz y formularios.
- styles.css — Estilos.
- app.js — Lógica (arrays, funciones, eventos).
- README.md — Documentación (este archivo).

## Cómo ejecutar
1. Clona el repositorio:
   git clone https://github.com/Ch1nis/Modulo-3-Evaluacion-de-portafolio.git
2. Abre index.html en el navegador (no requiere servidor si es estático).
3. Si usas un bundler o dependencias, sigue los scripts en package.json (npm install && npm start).
